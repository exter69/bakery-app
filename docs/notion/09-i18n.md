# 🌍 Internationalization

## Supported Languages

| Code | Language | Region |
|------|----------|--------|
| `en` | English | Default |
| `fr` | French | France/Belgium |
| `nl` | Dutch | Flemish (Belgium) |

---

## Implementation

Custom React context-based i18n (no external library):

```
frontend/src/i18n/
├── I18nContext.tsx    # React context + provider + useI18n hook
├── translations.ts   # All translation strings (Record<Locale, Record<string, string>>)
└── index.ts          # Re-exports
```

### Usage in Components

```tsx
import { useI18n } from '../i18n';

function MyComponent() {
  const { t } = useI18n();
  return <h1>{t('home.tagline')}</h1>;
}
```


---

## Language Detection

1. Check `localStorage` for saved preference
2. Fall back to browser language (`navigator.language`)
3. Default to `en` if no match

---

## Language Switcher

- `LanguageSwitcher` component in navigation
- Displays flag/code buttons (EN / FR / NL)
- Saves selection to localStorage
- Updates UI immediately (no page reload)

## Adding New Translations

1. Open `frontend/src/i18n/translations.ts`
2. Add new key to all three locale objects (`en`, `fr`, `nl`)
3. Use in component: `t('your.new.key')`

> 💡 All translation keys must exist in all locales. Missing keys will render the key string itself as fallback.
